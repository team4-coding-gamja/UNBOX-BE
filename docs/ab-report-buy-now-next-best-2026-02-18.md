# Buy Now A/B Report — Next Best Offer (Simulated)

## 0. 요약

- **배경**: unbox_trade 동시성 테스트에서 **Round2(락 실패 즉시 종료)**는 UX 이탈이 컸음.
- **가설**: 락 실패 시 **동일 옵션의 다음 최저가(Next Best)**를 제안하면 구매 전환이 개선된다.
- **실험 설계**: 시뮬레이터에서 Buy Now 흐름에 A/B 적용
  - **A(Control)**: 락 실패 시 종료
  - **B(Variant)**: 락 실패 시 Next Best 제안
- **결과**: B에서 **Buy Now 전환률이 +9.05%p 상승**(72.52% → 81.57%)
  단, **평균 가격 상승 +18,004원** 발생.

## 1. 실험 설정

- **Experiment ID**: `exp_cvr_home_v1`
- **데이터**: 30k users / 14일 시뮬레이션
- **총 이벤트 수**: 1,232,369
- **Buy Now 이벤트 수**: 91,223
- **비교 대상**: `flow = buy_now`

### 2.4 Paired 시뮬레이션 (50 runs, 동일 유저/랜덤 시퀀스)
> B에만 Next Best 경로를 추가하고, 같은 유저·같은 난수 흐름에서 A/B를 동시에 계산.

| Metric | Mean | 95% CI |
|---|---:|---:|
| A buy_now_cvr | 72.35% | [72.28, 72.41] |

| Δ buy_now_cvr | **+9.13%p** | [9.09, 9.17] |

| B lock_fail_pct | 22.02% | [21.95, 22.09] |
| A checkout_fail_pct | 7.22% | [7.18, 7.27] |

| B price_delta_median | 15,802.17 | [15,741.23, 15,863.11] |

**해석**
- **Δ buy_now_cvr(≈ +9.13%p)**는 모든 seed에서 안정적으로 재현되어, 효과가 랜덤 변동이 아닌 **처치(Next Best) 영향**임을 뒷받침함.
- **lock_fail_pct는 A/B 동일** → 효과는 “락 실패 이후 대응” 경로에서만 발생.
- **checkout_fail_pct는 소폭 개선** → 결제 실패는 기술적 실패 수준으로 유지.
- **price_delta 평균/중앙값이 안정적** → 전환 개선의 대가(가격 상승폭)가 일관되게 존재.

## 3. 이탈 사유 (B)

## 4. 해석

- **Next Best 제안으로 전환률이 유의하게 개선**됨.  
  (락 실패 시 즉시 종료 대비 구매 전환 +9.05%p)
- **가격 상승(평균 +18,004원)**이라는 트레이드오프가 존재.  
  → UX 개선 vs 가격 부담 간 균형 필요.
- 락 실패율 자체는 큰 변화 없음 → **처치 효과는 “락 실패 이후 대응”에서 발생**.

## 5. 동시성 테스트와의 연결

- Round2(락 실패 즉시 종료) → **고객 이탈 증가**
- Round3(Next Best) → **체결률 개선 가능성**  
  → 시뮬레이션 결과가 Round2→Round3 전환 논리를 정량적으로 뒷받침.
